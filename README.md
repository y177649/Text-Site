# オリジナルテキスト

レゴと3Dプリンターの、作り方テキストを配っているサイトです。

**サイト：https://y177649.github.io/Text-Site/**

ログインは要りません。パソコン・タブレット・スマホのブラウザで開けます。

## 使い方

1. **分類を選ぶ**：トップの「レゴのテキスト」か「3Dプリンターのテキスト」を押すと、その分類のテキストが簡単な順に並びます。
   トップには、公開して間もない「新しいテキスト」（右上に赤い New）と、よく使われている「おすすめのテキスト」も出ます。
2. **作るテキストを決める**：カードを押すと詳細ページが開きます。次の項目を見て、目の前の子に合うかを決められます。
   - 動くようすの動画（無いテキストもあります）
   - 難しさ（⭐。押すと目安が開きます）と、制作時間の目安
   - パーツ数（組み立てに使う部品の数）
   - 技術のタグ（そのテキストで使う仕組み）
   - 備考（作るときの注意。無ければ「-」）
3. **テキストを開く**：「テキストを開く」を押すと、テキスト本体（Google ドライブ・Google スライド）が開きます。

## 難しさ（⭐）の目安

| 難しさ | どんな子が作れるか | 制作時間の目安 |
|---|---|---|
| ⭐ | レゴを初めて作る子でもできる | 30分くらい |
| ⭐⭐ | 説明書を見て作品を何度か作ったことがある | 45分くらい |
| ⭐⭐⭐ | ほかのテキストをひととおり作ったことがある | 60分くらい |
| ⭐⭐⭐⭐ | メンターに聞かずにテキストを完成でき、2コマ続けて同じ作品を作れる | 90分くらい |

今の目安はレゴのテキスト用です。3Dプリンターのテキストは、目安が決まるまで「-」と表示しています。

## 技術のタグ

| タグ | 意味 |
|---|---|
| ギア | 歯車を組み合わせて動かす |
| 動力移動 | モーターの力を別の場所へ伝える |
| ステアリング | 車の向きを変える（曲がる）しくみ |
| アイコンブロック | 絵のブロックを並べてプログラミングする |
| ワードブロック | 文字のブロックを並べてプログラミングする |

## 困ったとき・作ってほしいテキストがあるとき

各テキストの詳細ページにある3つのボタンから送れます。ページの一番下の「お問い合わせ・報告」からも送れます。

- **問題を報告**：部品が足りない、説明と違う、ページが開かない など
- **お問い合わせ**：使い方などの質問
- **リクエスト**：こんなテキストがほしい、という要望

詳細ページのボタンから開くと、どのテキストについての相談かが最初から入っています。

## 記録していること

テキストがどれくらい使われているかを知るために、「テキストを開く」を押した回数だけを記録しています。
名前・メールアドレス・Google アカウントなど、使った人がわかる情報は記録しません。
くわしくは[プライバシーポリシー](https://y177649.github.io/Text-Site/privacy/)をご覧ください。
